Standard Operating Procedures

Traffic Stops

  • Maintain safe distance.
  • Request ID and reason for travel.
  • Search only with probable cause.
  • Escalate only when threat is shown.

Rules of Engagement

  • Verbal commands first.
  • Non-lethal if possible.
  • Lethal force authorized against armed threats.
  • Civilian safety is priority.

Arrests

  • State charges clearly.
  • Secure weapons.
  • Transport safely.
  • Log arrest in incident report.

Checkpoint Procedures

  • Minimum 2 NATO units required.
  • Use barriers and clear traffic lanes.
  • Search trucks entering major cities.
  • Report suspicious vehicles immediately.
  • One officer searches, one officer covers.
